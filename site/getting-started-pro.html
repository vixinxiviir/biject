Getting started with Bijection Pro

Thank you for buying it.

There is nothing to activate and no account to create. Bijection Pro is two things: the program, which you can download now, and a licence file, which is sent to you separately.

Download Bijection Pro

Pick the archive for your system; the table on that page says which. The downloads stay there, so you can come back for them on a new machine, and every 1.0.x update appears in the same place.

1. Your licence

It arrives by email within 24 hours, sent to the address you checked out with. Each licence is issued by hand, which is why it is not instant. You do not need to do anything to request it.

That email address is written into your licence, and into a comment at the top of every SQL file migrate generates. If you would rather it named a different address — a team alias, say — email licensing@bijection.dev with your order number, ideally before your licence arrives. It can be reissued later too.

Nothing after a day? Check your spam folder, then write to the same address.

2. Install the program

The download is the whole of Bijection plus migrate. It replaces the free biject if you have one: put it earlier on your PATH, or remove the free one.

  • Windows: move biject.exe into a folder on your PATH.
  • macOS: it is not code-signed, so clear the download quarantine once, then move it onto your PATH: 
    $ xattr -d com.apple.quarantine biject
$ sudo mv biject /usr/local/bin/
    It runs on both Apple Silicon and Intel Macs.
  • Linux: 
    $ sudo install -m 755 biject /usr/local/bin/
    It needs glibc 2.35 or newer, OpenSSL 3 and SQLite: Ubuntu 22.04, Debian 12, Fedora 36, current Arch, or later.
$ biject --version

3. Install your licence

When it arrives, save it with no file extension at the path for your system, creating the biject folder if needed:

Windows%APPDATA%\biject\license
macOS~/Library/Application Support/biject/license
Linux~/.config/biject/license

Or keep it anywhere and pass --license <FILE>. Then check it:

$ biject license

It prints who the licence is for and whether it covers this version. The check happens on your machine and sends nothing anywhere, so it works offline and on build servers. If it says the licence could not be verified, it was almost certainly damaged in copying; reply to the licence email for a fresh copy.

4. Use it

$ biject migrate --help

migrate writes SQL to a file and never runs it. Read what it writes before running it anywhere that matters.
